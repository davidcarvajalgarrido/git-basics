# Lección 2 — Ejercicios

## Ejercicio 1: Instala Git

1. Comprueba si Git está instalado ejecutando `git --version`.
2. Si no está instalado, descárgalo e instálalo desde la web oficial: https://git-scm.com/downloads
3. Verifica nuevamente que la instalación fue exitosa.

## Ejercicio 2: Configura tu identidad

1. Configura tu nombre de usuario global con `git config --global user.name "Tu Nombre"`.
2. Configura tu correo electrónico global con `git config --global user.email "tu@email.com"`.
3. Comprueba que los valores se han guardado correctamente con `git config --list`.

## Ejercicio 3: Personaliza la configuración básica

1. Cambia la rama por defecto para nuevos repositorios a `main` con `git config --global init.defaultBranch main`.
2. Elige y configura tu editor de texto favorito para Git (por ejemplo, `git config --global core.editor notepad` o el editor que prefieras).
3. Muestra toda la configuración global de Git y explica brevemente para qué sirve cada ajuste que has realizado.
